# 검사

## 전체흐름.mjs

제안요청서를 던져 제안서가 나오고, 그걸 이어서 고치고, PPT 로 내보내기까지
**한 번에 돌려 보는 검사**입니다. AI 자리에는 진짜 Claude 가 돌려줄 법한 답을
끼워 넣습니다 (열쇠 없이도 돌릴 수 있게).

```
npm run dev            # 다른 창에서 띄워 두고
node 검사/전체흐름.mjs 검사
```

확인하는 것 13가지

1. 한글(.hwp) 제안요청서를 대화창에 끌어다 놓으면 글이 꺼내지는가
2. 그 글이 실제로 AI 에게 넘어가는가
3. AI 가 지난 제안서의 내용까지 보는가
4. 제안서가 만들어지는가
5. 요청서가 그 건의 파일함에 남는가
6. 빈칸이 아니라 실제 글이 들어가는가
7. 만들자마자 편집 화면이 열리는가
8. 이어지는 대화에서 AI 가 제안서 전체를 보는가
9~11. 여러 장이 한 번에 고쳐지는가
12. 손으로 고치고 되돌리기가 되는가
13. PPT 로 나가는가

## 시험자료/

한글(.hwp · .hwpx) · 워드 · 파워포인트 · 엑셀 시험 파일.
`node 검사/시험자료만들기.mjs 검사/시험자료` 로 다시 만들 수 있습니다.
